# Vim 常用命令一日学习路线

> **目标**：零基础起步，一天内让「日常编辑文件的常用命令」达到熟练——能高效地打开、定位、增删改查、批量替换、多文件切换与保存退出。
> **总时长**：净学习约 7.5 小时（上午 3 站 + 下午 4 站，站间休息 10 分钟），一天完成。
> **版本基线**：Vim 9.1（官方用户手册 2025-07 基线），已与官方在线帮助文档（Vim 9.2）目录逐章核对一致；内容在 Vim 8.x 上同样适用。
> **内容构成**：全部知识点提炼自 Vim 官方用户手册第 02/03/04/05/06/07/08/10/20/24 章（`/usr/share/vim/vim91/doc/`，与官方在线帮助同源）及内置交互教程 vimtutor。正文无外部链接，读不通时可随时在 Vim 内用 `:help` 印证。
> **不覆盖**：插件生态、Vim script 编程、高级定制（列入文末「后续深入主题」）。

1. **确认 Vim 可用**：终端执行 `vim --version`，能看到版本号即可（macOS/Linux 自带；Windows 建议 Git Bash 或 gvim）。

**全天候保命口诀**：迷路了、乱了、不知道发生了什么——先按 `<Esc>`（必要时按两下），再想下一步。

## 第 1 站：生存第一课（60 min）

### 目标

打开一个文件，进入插入模式打字，改几个错，不保存退出和保存退出都走一遍——从此不再"被困在 vim 里"。

### 知识提炼

**Vim 是模式编辑器**。两种基本模式：

- **Normal（普通）模式**：按键是命令（刚启动时就在这里）
- **Insert（插入）模式**：按键就是打字

| 命令 | 作用 |
|---|---|
| `i` | 在光标**前**进入插入模式（i = Insert） |
| `<Esc>` | 回到 Normal 模式（乱局万能解，多按无害） |
| `:set showmode` | 在底行显示当前模式（新手期建议开着） |

> 易错点：在插入模式里把命令当文字打了进去。先 `<Esc>` 回 Normal 模式稳住局面；这些误输入待会儿学完下面的「撤销与重做」，一个 `u` 就能清掉。

**启动与界面**：`vim 文件名` 启动（`gvim 文件名` 则另开窗口）。`~` 行表示"文件到此为止"；底行显示文件名和状态（如 `[New file]`）。

**光标移动**（Normal 模式）：

| 键 | 方向 |
|---|---|
| `h` | 左 |
| `j` | 下 |
| `k` | 上 |
| `l` | 右 |

方向键也能用，但手要离开主键区，一小时几百次就慢多了。记忆图：

```
        k
    h       l
        j
```

**删除与合并**（Normal 模式）：

| 命令 | 作用 |
|---|---|
| `x` | 删光标处一个字符 |
| `dd` | 删整行 |
| `J` | 把下一行接到本行末尾（删掉换行符） |

> 埋个钩子：`x` 一次只能删一个字符，太慢了？第 3 站的「操作符 + 动作」会给出系统性答案。

**插入家族**：

| 命令 | 作用 |
|---|---|
| `i` | 光标前插入 |
| `a` | 光标后插入（a = Append，行尾追加必用） |
| `o` | 在下方新开一行并进入插入模式 |
| `O` | 在上方新开一行并进入插入模式 |

**撤销与重做**：

| 命令 | 作用 |
|---|---|
| `u` | 撤销上一次修改（可连续按，一直撤到文件打开时） |
| `CTRL-R` | 重做（撤销掉头了就按它） |
| `U` | 一次撤销本行上的全部修改（按两次 U 互相抵消；U 本身也是一次修改，可以被 u 撤销） |

**计数前缀**：数字放在命令**前面**放大效果——`9k` 上移 9 行，`3x` 删 3 个字符，`3a!<Esc>` 追加 3 个感叹号。

**退出与保存**：

| 命令 | 作用 |
|---|---|
| `ZZ` | 保存并退出（注意是大写，等于"存盘走人"） |
| `:w` | 保存不退出（w = write，冒号命令按回车执行） |
| `:q!` | 不保存强制退出（! = 我知道会丢修改，别拦我） |
| `:e!` | 放弃修改，重新从磁盘加载文件 |

> 遇到 `E37: No write since last change` 是 Vim 在保护你：有未保存修改就不让走。`:help E37` 可查任何错误码。

**内置求助系统**（学 Vim 最重要的命令）：

| 命令 | 作用 |
|---|---|
| `:help` 或 `<F1>` | 打开总帮助 |
| `:help x` | 查 x 命令 |
| `:help i_CTRL-W` | 查插入模式下 CTRL-W（`i_` 前缀 = 插入模式） |
| `:help 'number'` | 查选项（选项名加单引号） |
| `:help index` | 全部命令总索引 |
| `CTRL-]` | 光标在竖线链接（如 |help|）上时跳转 |
| `CTRL-T` / `CTRL-O` | 跳回上一个位置 |
| 输入主题后按 `CTRL-D` / `<Tab>` | 列出候选主题 / 补全 |

帮助窗口本身就是普通 Vim 窗口：hjkl 照常滚动，`ZZ` 只关帮助不退出 Vim。

### 动手练习（勾选清单）

- [ ] 新建练习文件：终端 `mkdir -p /tmp/vim练习 && vim /tmp/vim练习/hello.txt`

- [ ] 用 `o` 新开一行写一句话，用 `O` 再开一行
- [ ] 用 `dd` 删一行，`u` 撤回，`CTRL-R` 重做

## 第 2 站：精准移动与搜索（60 min）⭐ 核心

### 目标

在一屏乃至上千行的文件里，几秒内把光标放到目标位置；会用搜索定位任意字符串。

### 知识提炼

**词级移动**（小写 = 词 word，大写 = WORD，以空格分隔的"串"）：

| 命令 | 作用 |
|---|---|
| `w` | 下一个词的开头 |
| `b` | 上一个词的开头 |
| `e` | 下一个词的结尾 |
| `ge` | 上一个词的结尾 |
| `W` `B` `E` | 同上，但按空格分隔的 WORD 跳，跨标点更快 |

都支持计数：`3w` 前进三个词。词的边界遇 `.`、`-`、`)` 等非单词字符会断开。

**行首行尾**：

| 命令 | 作用 |
|---|---|
| `0` | 行首第一个字符 |
| `^` | 行首第一个**非空白**字符 |
| `$` | 行尾（`2$` = 下一行的行尾） |

**行内字符查找**（本行内，不跨行）：

| 命令 | 作用 |
|---|---|
| `f{字符}` | 向右找到该字符（f = Find），如 `fh` |
| `F{字符}` | 向左找 |
| `t{字符}` | 向右停在目标字符**前**一格（t = To） |
| `T{字符}` | 向左停在后一格 |
| `;` | 重复上一次 f/F/t/T |
| `,` | 反方向重复 |

> 按错方向了？`f<Esc>` 取消本次查找。`<Esc>` 能取消大多数未完成的操作。

**括号配对**：`%` 在 `(` `)`、`[` `]`、`{` `}` 之间来回跳。光标不在括号上时会向前找最近一个括号再跳。改代码必会。

**行号定位**：

| 命令 | 作用 |
|---|---|
| `gg` | 跳到文件第一行 |
| `G` | 跳到文件最后一行 |
| `33G` | 跳到第 33 行（编译器报错 `line 33` 直接用） |
| `50%` | 跳到文件 50% 处 |
| `H` `M` `L` | 跳到**屏幕**顶部/中部/底部行（High/Middle/Low） |

**滚动**：

| 命令 | 作用 |
|---|---|
| `CTRL-D` / `CTRL-U` | 下/上半屏 |
| `CTRL-F` / `CTRL-B` | 下/上整屏（Forward / Backward） |
| `CTRL-E` / `CTRL-Y` | 下/上滚一行 |
| `zz` / `zt` / `zb` | 让光标行居中/置顶/置底 |

**搜索**（跨行全文）：

| 命令 | 作用 |
|---|---|
| `/字符串` 回车 | 向下搜索 |
| `?字符串` 回车 | 向上搜索 |
| `n` | 下一个匹配（同方向） |
| `N` | 上一个匹配（反方向） |
| `3n` | 第 3 个匹配 |

搜索历史：输 `/` 后用 `<Up>`/`<Down>` 翻历史；`:` 命令有独立的一套历史。

**光标词搜索**：光标停在词上按 `*` 直接搜它（整词），`#` 反向搜；`g*`/`g#` 允许部分匹配。

**搜索模式（正则）入门**：

- `^include` 只匹配行首的 include；`the$` 只匹配行尾
- `\<the\>` 整词匹配 the（不会命中 there、soothe）
- `.` 匹配任意一个字符；`ter\.` 中的 `\.` 转义后只匹配真正的句点
- 特殊字符 `.*[]^%/\?~$` 想按字面搜索时要加 `\`

**搜索体验三选项**：

| 命令 | 作用 |
|---|---|
| `:set ignorecase` | 忽略大小写（`:set noignorecase` 恢复） |
| `:set incsearch` | 边打边高亮第一个匹配，回车确认 |
| `:set hlsearch` | 高亮所有匹配；`:nohlsearch` 只临时清掉本次高亮 |

> 埋个钩子：这几个选项很好用，但每次启动都要重设——第 7 站把它们写进 vimrc 永久生效。

**我在哪**：`CTRL-G` 显示文件名/行号/百分比/列号；`:set number` 显示行号（`:set nonumber` 关闭）；`:set ruler` 在右下角常驻坐标。

**标记与跳回**：

| 命令 | 作用 |
|---|---|
| ` ` `（双反引号） | 跳回出发位置（可来回按） |
| `CTRL-O` | 沿跳转历史往回（Older） |
| `CTRL-I` | 往前（和 O 相邻的键） |
| `:jumps` | 列出跳转历史 |
| `ma` | 把当前位置记为标记 a（a–z 共 26 个） |
| `` `a `` | 精确跳到标记 a |
| `'a` | 跳到标记 a 所在行行首 |
| `''` | 跳回上次跳转前的位置 |
| `:marks` | 列出所有标记 |

判定标准：`G`、搜索、`gg` 这类"跨行大跳"算 jump（可被 `` ` `` / CTRL-O 跳回）；`fx`、`w`、`j` 不算。

### 动手练习（勾选清单）

- [ ] 继续用 `/tmp/vim练习/` 下的文件，或 `vimtutor` 第二章相应课程
- [ ] 粘贴/输入 20 行以上文本；练习 `w` `b` `e` `3w` `2b` 各 10 次

## 第 3 站：高效删改（75 min）⭐ 核心中的核心

### 目标

掌握 Vim 的招牌思维——**操作符 + 动作**：学会了 `d` 加上你已经会的移动命令，就自动获得了几十个删除命令。第 1 站埋的钩子现在兑现——`x` 一个字符一个字符删太慢，答案就在这一站。这是全天价值密度最高的 75 分钟。

### 知识提炼

**操作符 + 动作（operator + motion）**：先按操作符（想干什么），再按动作（范围多大）：

```
d2w   =  d（删除） + 2w（移到两个词之外）  → 删两个词
d$    =  删到行尾
d4w   =  删四个词
```

规则：删除范围 = 从光标到动作落点。落点字符是否包含取决于动作——`w` 不包含下个词首字符（exclusive），`e` 和 `$` 包含落点（inclusive）。这就是官方口径的 exclusive / inclusive。

**change 操作符 `c`**：和 `d` 一样接受动作，但删完进入插入模式：

| 命令 | 效果 |
|---|---|
| `cw` | 改一个词（**特例**：实际等于 `ce`，不含词后空格——从 Vi 时代沿用至今） |
| `c2w` | 改两个词并开始输入 |
| `cc` | 改整行（保留行首缩进） |
| `c$` | 从光标改到行尾 |

**高频单键快捷方式**（全是 operator+motion 的缩写）：

| 键 | 等价于 | 作用 |
|---|---|---|
| `x` | `dl` | 删光标处字符 |
| `X` | `dh` | 删光标左边字符 |
| `D` | `d$` | 删到行尾 |
| `C` | `c$` | 改到行尾 |
| `s` | `cl` | 改一个字符 |
| `S` | `cc` | 改整行 |

**计数的两种放法**：`3dw`（删一个词三次）和 `d3w`（删三个词一次）结果一样；`3d2w` = 2 词 × 3 次 = 6 个词。

**替换**：

| 命令 | 作用 |
|---|---|
| `r{字符}` | 把光标处一个字符替换掉（如 `rT`），不用回 Esc |
| `5rx` | 连续 5 个字符都换成 x |
| `r<Enter>` | 把一个字符换成换行（断行） |
| `R` | 进入 Replace 模式，打一个字盖一个字，`<Esc>` 退出；`<Insert>` 键可与插入模式互切 |

**`.` 重复命令**：重复上一次修改。Vim 站牌级生产力：

```
/four<Enter>   找到第一个 four
cwfive<Esc>    改成 five
n              找下一个
.              重复刚才的修改
n . n . ...    一路推完
```

`.` 对一切修改生效（`u`、`CTRL-R`、冒号命令除外）。

**文本对象（text object）——第三种改法**：光标在词中间时不必先移到词首：

| 命令 | 含义 |
|---|---|
| `daw` | Delete A Word：删整个词（含词后空格） |
| `diw` | 删词但不含周围空格（Inner） |
| `cis` | 改整个句子（Inner Sentence，不留句间空白） |
| `cas` | 改整个句子（A Sentence，含句后空白，用于删除场景） |

规律：`d/c/y + i或a + 对象`。`i` = 只取内部，`a` = 连边界（含空白）一起。`v` 可视模式下用 `as` 可以连续扩选句子。

**常用删除命令全家福**（官方 04.10 总结，每个都由你已学的部件拼成）：

```
x    删光标字符          dw   删到下个词首
X    删光标左字符        db   删到上个词首
D    删到行尾            diw  删词（不含空格）
dG   删到文件末尾        daw  删词（含空格）
dgg  删到文件开头
```

把 `d` 换成 `c` 就得到同范围的修改命令，换成 `y` 就是复制命令（第 4 站正式讲 y）。

**可视模式（Visual mode）——先选后删**：

| 按键 | 模式 |
|---|---|
| `v` | 字符可视（选到哪亮到哪） |
| `V` | 行可视（整行整行地选） |
| `CTRL-V` | 块可视（矩形选区，做表格/对齐神器） |

选完后按操作符（如 `d`）作用于选区；`<Esc>` 放弃选择。选区两端要调整：`o` 跳到另一端，块模式下 `O` 在同行两个角间切换。（注意：可视模式里的 `o`/`O` 与 Normal 模式开新行的 `o`/`O` 完全是两回事。）

> 埋个钩子：行可视选中后按 `:` 会发生什么？第 5 站的范围命令 `<:'>` 会兑现。

**顺手记住的两个插入系命令与一个换挡键**（官方 04.10 同列表）：

| 命令 | 作用 |
|---|---|
| `I` | 跳到行首第一个非空白处进入插入 |
| `A` | 跳到行尾进入插入（写行尾注释极常用） |
| `~` | 光标处字符大小写互换并右移（可视模式下作用于整个选区） |

### 动手练习（勾选清单）

## 第 4 站：复制·粘贴·大小写·排版（60 min）

### 目标

文本在文件里自由搬家；一行变大小写、批量缩进、重新排版都一键完成。

### 知识提炼

**粘贴 `p` / `P`**（put，放/前放）：

- 删掉的内容没有消失——`dd` 后移到别处按 `p`，整行放回光标**下方**
- 删的是行内片段（如 `dw`），`p` 把它放到光标**后面**
- `P` 与 `p` 相反（行则放上方，词则放光标前）
- `3p` 连贴三份；可反复贴，寄存器内容不变

**交换两字符**：手滑打成 `teh`？光标停在 e 上按 `xp`（x 删 e，p 贴到 h 后面）——the！

**复制 = yank（y）**：既然 `c` 被占用，Vim 把复制叫做 yank（拽）：

| 命令 | 作用 |
|---|---|
| `yw` | 拽一个词（含词后空格；不要空格用 `ye`） |
| `y2w` | 拽两个词 |
| `yy` | 拽整行 |
| `Y` | 等同 `yy`（注意与 `D`≠`dd` 不同，这是官方承认的不一致！） |
| `y$` | 拽到行尾 |

y 完用 `p`/`P` 粘贴。Vim 记得你复制的是整行还是片段，贴的时候形态不变。

**命名寄存器**：多处复制不打架——复制前加 `"f`（f 可以是 a–z 任意字母）：

```
"fyas      把一句话拽进寄存器 f
"l3Y       把三行拽进寄存器 l
"wdaw      删一个词并放进寄存器 w
"fp        把寄存器 f 的内容贴出来
```

大写寄存器 = 追加：`"aY` 拽一行进 a，再到另一行 `"AY`，a 里就攒了两行。
**系统剪贴板**：`"*yy` 复制到系统剪贴板，`"*p` 从剪贴板贴进来（需 Vim 编译带 clipboard 支持）。
可视模式配寄存器：`CTRL-V jj ww "b y` 把一个块拽进寄存器 b（注意 `"b` 要紧贴在 `y` 前）。

**大小写操作符**（都是 operator，可接动作/文本对象/可视选区）：

| 命令 | 作用 |
|---|---|
| `gUw` | 一个词转大写（GU → gU + w） |
| `guw` | 一个词转小写 |
| `g~w` | 大小写互换 |
| `gUU` / `guu` / `g~~` | 整行大写/小写/互换（操作符按两次 = 作用于整行） |
| 可视模式 `U` / `u` / `~` | 选区转大写/小写/互换 |

**缩进**：

| 命令 | 作用 |
|---|---|
| `>>` / `<<` | 当前行右移/左移一格缩进 |
| `3>>` | 三行一起右移 |
| `:set shiftwidth=4` | 定义"一格"= 4 空格 |
| 可视模式选中后 `>` / `<` | 选中的行整体缩进 |

**合并与排版**：

| 命令 | 作用 |
|---|---|
| `J` | 合并下一行（换行处挤成一个空格）；`gJ` 原样拼接不加空格 |
| `:set textwidth=72` | 输入时自动在 72 列断行 |
| `gqap` | 重新排版当前段落（ap = A Paragraph，以空行分段） |
| `gggqG` | 重排整个文件（gg 到顶 + gq + G 到尾的动作） |

> 注意：含空白的"空行"不算段落分隔符——这是官方专门提醒的坑。

> 埋个钩子：寄存器 a–z 还有一副面孔——第 5 站的宏录制用的正是同一套寄存器。

### 动手练习（勾选清单）

## 第 5 站：批量替换与重复劳动自动化（75 min）⭐ 核心

### 目标

十处、百处同样的修改一条命令搞定；十行同样的操作录一遍宏自动重放；列编辑、外部命令文本管道都会用。

### 知识提炼

**替换命令 `:s`（substitute）**：

```
:[范围]s/from/to/[flags]
```

| 命令 | 作用 |
|---|---|
| `:s/Professor/Teacher/` | 只改**当前行**第一处 |
| `:s/Professor/Teacher/g` | 当前行全改（g = global，本行内所有） |
| `:%s/Professor/Teacher/g` | **全文件**所有行全改（`%` = 所有行） |
| `:%s/Professor/Teacher/c` | 每处先确认再改 |
| `:%s/Professor/Teacher/gc` | 全文件 + 逐处确认（最稳的日常姿势） |

`c` 确认时的应答：`y` 改 / `n` 跳过 / `a` 剩下全改 / `q` 不改了退出 / `l` 改完这处就停。

from 部分是搜索用的**模式**（第 2 站的正则直接适用）：`:s/^the/these/` 只改行首。路径里有斜杠？换分隔符：`:s+one/two+one or two+`。

**命令范围（range）——一大半冒号命令通用**：

| 写法 | 含义 |
|---|---|
| `:1,5s/this/that/g` | 第 1–5 行替换（含第 5 行） |
| `:54s/President/Fool/` | 只第 54 行 |
| `:.,$s/yes/no/` | 当前行到最后一行（`.` = 当前行，`$` = 末行） |
| `%` | 等价 `1,$` |
| `:?^Chapter?,/^Chapter/s=grey=gray=g` | 从向上第一个 Chapter 行到向下第一个 Chapter 行（`?…?` 向前找，`/…/` 向后找；`s=` 是换了分隔符的 s 命令） |
| `/Chapter/-1` | 匹配行的上一行；`/Chapter/+2` 是下两行；可组合如 `:.+3,$-5` |
| `:'t,'b s/.../.../g` | 标记 t 行到标记 b 行之间（`mt` / `mb` 先打标记） |
| 可视模式选中后按 `:` | 自动填出 `:'<,'>`，接着补命令即可——**这就是第 3 站埋的钩子** |
| 先按 `5:` | 自动填出 `:.,.+4`（当前行起共 5 行） |

**全局命令 `:g`**：对**匹配行**执行冒号命令（默认范围就是全文件，这点与 `:s` 不同）：

```
:g+//+s/foobar/barfoo/g    只在含 // 的行里把 foobar 换成 barfoo
```

结构：`:g/{模式}/{命令}`。

**宏：录制与重放（q 命令）**：

```
qa        开始录制到寄存器 a（就是第 4 站那套 a–z 寄存器！）
…一组操作…
q         停止录制（单独一个 q）
@a        重放
3@a       重放 3 次
@@        重放最近一次的宏
```

官方实例——把裸文件名变成 `#include "xxx.h"`：

```
qa ^ i#include "<Esc> $ a"<Esc> j q     录一遍
3@a                                      剩下三行自动完成
```

宏 vs `.`：`.` 只能重复**一次**修改；宏能串起移动+多次修改，还能存 26 份。
宏录错了不用重来：`G` `o<Esc>` 把寄存器当文本贴出来改（`"np` → 修改 → `0"ny$` → `dd`），再 `@n`。
`qC` = 追加录制到 a 寄存器（大写追加规则再次生效）。

**可视块列编辑**（CTRL-V 选好矩形后）：

| 命令 | 作用 |
|---|---|
| `I文本<Esc>` | 在块**左侧**每行插入（Esc 后才批量生效） |
| `A文本<Esc>` | 在块**右侧**每行追加（短行也加；先按 `$` 再 `A` 则加到每行行尾） |
| `c文本<Esc>` | 删块并插入 |
| `C文本<Esc>` | 从块左缘删到行尾再插入 |
| `r{字符}` | 整块填同一字符 |
| `~` / `U` / `u` | 块内大小写互换/转大写/转小写 |

规则：块没够到的短行，`I`/`c` 不动它，`A` 会加。

**外部程序当文本过滤器**：

| 命令 | 作用 |
|---|---|
| `!5Gsort<Enter>` | 当前行到第 5 行过一遍 sort 再放回 |
| `!!date<Enter>` | 当前行替换成 date 命令输出（盖时间戳） |
| `:read !ls` | 把 ls 输出插到光标下方 |
| `:0read !date -u` | 在文件最顶插入 UTC 时间 |
| `:write !wc` | 把当前文件喂给 wc 统计行/词/字数 |

> 空格敏感陷阱：`:write !wc` 是"交给 wc"，`:write! wc` 是"强制写到名为 wc 的文件"！
> 外部命令把屏幕搞花了？`CTRL-L` 重绘。

**读入文件**：`:read 文件名`（插到光标下）、`:$r 文件名`（附加到文末）、`:0read 文件名`（插到最顶）。

## 第 6 站：多文件编辑与窗口分屏（60 min）

### 目标

一个 Vim 会话里顺序编辑一批文件、两个文件间来回横跳、分屏对照，只读保护和备份机制也搞清楚。

### 知识提炼

**在 Vim 内换文件**：

| 命令 | 作用 |
|---|---|
| `:edit foo.txt` | 关掉当前、打开 foo（有未存修改会报 E37） |
| `:edit! foo.txt` | 丢弃修改强行换 |
| `:hide edit foo.txt` | 把当前文件藏起来换页（改动还在） |
| `:write` | 保存当前文件 |

**文件参数列表（启动时给一批）**：

```
vim one.c two.c three.c     一次开三个
:next        下一个（有修改会拦）
:wnext       保存并下一个
:previous / :wprevious      上一个 / 保存并上一个
:first / :last              第一个 / 最后一个
:2next                      向前跳两个
:args                       查看列表，当前文件带 [] 
:args *.txt                 不退出 Vim 重定义列表
```

保护机制：列表没走完就想退出，Vim 报 `E173: 46 more files to edit`——再退一次才放行。
嫌每次手动 `:w` 烦？`:set autowrite` 在 `:next` 等切换时自动保存。

**两文件横跳**：`CTRL-^` 在当前文件和"替补文件"（alternate，上一个编辑的文件）之间来回。

**全局标记**：小写标记（`ma`）只属于单个文件；**大写标记跨文件**——`50%mF` 在 foo.txt 半程做标记 F，切到任何文件按 `'F` 直接飞回来。

**只读与改名**：

| 命令 | 作用 |
|---|---|
| `vim -R file`（或 `view file`） | 只读打开，`:w` 会被拦 |
| `vim -M file` | 完全只读，改都不让改（改了报 E21） |
| `:saveas move.c` | 另存为新文件并切换过去 |
| `:file move.c` | 只改 Vim 认定的文件名不落盘（防止误覆盖已有文件时报 E13） |

**备份**：默认不备份。`:set backup` 后保存时生成 `文件名~`；`:set backupext=.bak` 改后缀；`:set patchmode=.orig` 首次修改前永久留一份原始拷贝。

**窗口分屏**：

| 命令 | 作用 |
|---|---|
| `:split`（`:sp`） | 横切一屏（上下） |
| `:split two.c` | 横切并打开另一文件 |
| `:3split alpha.c` | 指定新窗口 3 行高 |
| `:vsplit`（`:vs`） | 竖切（左右） |
| `:new` / `:vnew` | 分屏打开空新文件 |
| `:vertical 命令` | 让任何分屏命令改走竖切 |

**窗口间移动**（和光标移动同一套字母，前面加 CTRL-W）：

```
CTRL-W w    在窗口间轮流跳
CTRL-W h/j/k/l    跳到左/下/上/右窗口
CTRL-W t / b      跳到最上/最下窗口
```

**窗口管理**：

| 命令 | 作用 |
|---|---|
| `CTRL-W +` / `CTRL-W -` | 增大/减小当前窗口（可带计数 `4 CTRL-W +`） |
| `CTRL-W _` | 当前窗口撑到最大 |
| `CTRL-W K` | 当前窗口移到最顶并占满宽度 |
| `:close` | 关当前窗口（关最后一个也不会退出 Vim，安全） |
| `:only` | 只留当前窗口，其余全关（有未存修改的会拦下） |

### 动手练习（勾选清单）

- [ ] 终端 `vim one.txt two.txt three.txt`（先建三个文件），用 `:wnext` 走完三个，`Ctrl-C` 前先体验 `:args` 查看位置

- [ ] `:split` 上下两窗看同一文件的不同位置；`CTRL-W w` 轮流跳
- [ ] `:vsplit two.txt` 左右对照两个文件

- [ ] `:close` 逐个关窗，体会它和 `:q` 的区别

### 过关自检

1. `:next` 被拒了，想保住修改继续，用什么；想丢弃呢？

## 第 7 站：配置固化 + 毕业实战（60 min）

### 目标

把这两天反复手敲的 `set` 命令固化成自己的 `~/.vimrc`（只讲最基本的三五行，不碰插件），然后通过毕业实战把全天所学串成肌肉记忆。

### 知识提炼

**vimrc 文件**：Vim 启动时自动执行的命令清单。位置：

- Unix / macOS：`~/.vimrc`
- Windows：`$HOME/_vimrc`

第一次创建时，官方建议首行加上：

```vim
source $VIMRUNTIME/defaults.vim
```

它给新用户加载一套现代默认行为（nocompatible、退格能删换行、历史 200 条、ruler、showcmd、wildmenu、incsearch 等）。vimrc 里可以写所有冒号命令，改完**重启 Vim 生效**。

**推荐起步配置**（每一行都是正文教过的选项，逐条都能 `:help 'xxx'` 印证）：

```vim
source $VIMRUNTIME/defaults.vim
set number          " 行号（第 2 站）
set ruler           " 右下角坐标（第 2 站）
set incsearch       " 边搜边预览（第 2 站）
set hlsearch        " 高亮全部匹配（第 2 站）
set ignorecase      " 搜索忽略大小写（第 2 站）
set shiftwidth=4    " 缩进步长 4 空格（第 4 站）
syntax enable       " 语法高亮（官方第 6 章）
```

**相关命令**：

| 命令 | 作用 |
|---|---|
| `:edit $MYVIMRC` | 直接打开当前生效的 vimrc |
| `:scriptnames` | 列出 Vim 启动加载过的脚本（排查配置不生效） |
| `:set filetype` | 看当前文件类型识别结果；`:set filetype=make` 手动指定 |
| `:set background=dark` | 配色适配深色终端（**必须写在 syntax enable 之前**） |
| `:colorscheme evening` | 换配色方案（可用名字见 `$VIMRUNTIME/colors` 目录） |

语法高亮无效时按官方清单排查：终端不支持颜色 → 换终端；文件类型没识别 → `:set filetype=...`；配色刺眼 → `background=dark`。个别语法高亮滚动后错色，`CTRL-L` 刷新。

### 毕业实战（三选二必做）

**实战一：真实文件大扫除（衔接真实工程形态）**

拿一个你真实的配置/文本文件（如 `~/.zshrc`、项目的 `README.md` 或一个 CSV 日志），只靠 Vim 完成一轮维护，操作清单：

1. `vim 目标文件`，`:set number` 核对行数
2. `/关键词` 定位问题点，`daw`/`cc`/`D` 精准修整
3. `:%s/旧词/新词/gc` 做一次确认式全局替换
4. `V` 选中一段做 `>` 缩进或 `gqap` 重排
5. 用 `q` 录一个小宏处理 5 处同类格式问题
6. `ZZ` 保存退出，终端里 diff/cat 检查战果

**实战二：vimtutor 第二章**

`:Tutor`（或终端 `vimtutor`）进入第二章课程，全部课程做完——它就是把本路线第 3–5 站的命令换了套文本再练一遍。

**实战三：三文件周报汇总项目**

模拟真实工作流：三个素材文件汇成一份报告，全程不退出 Vim：

1. 终端建 `mon.txt` `tue.txt` `wed.txt` 各写两条待办，然后 `vim mon.txt tue.txt wed.txt`
2. 在 mon.txt 里 `"ayy` 把两行收进寄存器 a，`:wnext` 到 tue，重复 `"AY` 攒行
3. 最后一个文件里 `:edit report.md` 新建报告
4. `A## 本周汇总<Esc>` 写标题，`o` 新行，`"ap` 一次性贴出攒好的三天的行
5. `:%s/TODO/DONE/gc` 批量勾掉已完成的
6. `:0read !date` 在顶部插入生成日期
7. `gggqG` 重排，`mt` `G` 用 `:'t,$s/^$/---/` 给空行加分隔线（`^$` = 行首紧跟行尾，即空行；这是第 2 站 `^` 和 `$` 的组合应用，也是范围命令收尾）
8. `ZZ` 保存，`cat report.md` 验收

## 学习原则

1. **手上过一遍，才算学过**：Vim 是肌肉记忆学科。本路线每个命令都配了练习，跳过练习 = 白学。宁可少看一节文字，不可少敲十个命令。
2. **两遍学习法**：第一遍照本路线走完全天 + 毕业实战；第二遍（本周内）精读官方手册第 12 章「Clever tricks」和第 26 章「Repeating」，再用 `:help quickref` 把速查表对一遍——第二遍会陡然提速。
3. **迷路就 Esc**：任何时刻不确定自己在哪个模式、按了什么，`<Esc>` 一按回 Normal，天塌不下来；改错了 `u` 一直按。
4. **求助系统优先于搜索引擎**：`:help` 永远和你本机版本一致。报错先 `:help E错误码`。
5. **组合思维**：操作符（d/c/y/gU/gq）× 动作（w/$/G）× 文本对象（iw/as）× 计数 = 学 10 个部件会用 100 个命令。学新命令时先问"它是哪个操作符的缩写？"
6. **别贪快**：一天练完标准是"命令能不假思索敲出"，不是"看完记住"。第 2、3、5 站值得第二天再练 30 分钟。
